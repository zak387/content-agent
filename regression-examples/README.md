# Regression Examples

The cheapest evaluation discipline that works. Keep **five real inputs** here covering different scenarios:

1. A challenge-Monday with a clear measurable challenge.
2. A Tuesday viral adaptation where good trending posts exist.
3. A Wednesday lead magnet with a real asset.
4. A Thursday personal story with a rich story-bank entry.
5. An edge case (e.g. a Friday where the challenge FLOPPED — agent must report honestly).

## How to use
After any meaningful change to a skill or CLAUDE.md:
1. Run the pipeline on all five inputs.
2. Read the outputs side by side with last week's saved outputs.
3. Better → the change helped. Same/worse → revert it.

Save each run as `example-<n>/<date>-output.md` so you can diff over time.
