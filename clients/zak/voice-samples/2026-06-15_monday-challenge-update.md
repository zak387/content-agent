# Voice Sample — Monday Challenge Update (newsletter agent / Risalla) — 2026-06-15

Funny how everyone seems to have cracked the AI usage piece.

Every other post is about Claude Code now, or this AI GTM motion that fills your pipeline on autopilot, or the latest AI marketing skills that write copy, create ads, and schedule newsletters.

And I'm honestly skeptical most of the time. The reason being, we're trying to create an AI capability (not a Claude skill, not a chatbot, not a GPT artifact) that actually writes great copy.

Not ANY copy.

More particularly, emails and newsletters.

And trust me when I tell you, it's way more complex than just handing a video transcript to Claude and asking it to make a newsletter out of it.

Or voice-dumping your thoughts and asking it to be concise and preserve your tone and voice.

This is coming from someone who has sent more than 300k emails in the last 90 days.

This isn't an attempt to complain about how hard it is, but to give you an insider perspective on what it really means to write effectively with AI.

For context: I've been challenged by my co-founder to produce an AI agent that writes freaking amazing newsletters for creator-preneurs and education companies.

And here's where we landed:

- Produced a decent V1 writer for one creator, using his old content and rules that make the writer sound less like AI
- Curated a corpus from a great writer, analyzed how he writes, how he opens sentences, how he uses evidence and humor, how he delivers information, how he transitions from one paragraph to another, and added the findings as instructions for the agent
- Turned the writer from a markdown file + Python script into a bunch of skill files + an orchestrator agent + a bunch of Python scripts. All of that to say: we have a much better architecture for the agent now
- Still grappling with maintaining quality across different profiles/creators

So yes, I don't think it's as easy as "download this skill file that'll make your writer 10x better."

That's it for me. If you're interested in seeing what the agent produces, make sure to follow along.
